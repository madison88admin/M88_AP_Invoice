1. System Overview

The AP Invoice Automation System is a comprehensive web-based platform that automates the accounts payable invoice processing workflow for Madison 88.

Key Capabilities

  • OCR-based invoice extraction from PDF files using AI (Ollama qwen3:14b)
  • Multi-stage approval workflow with role-based signatories
  • PO validation against NextGen MPO data
  • Exception handling for discrepancies and variances
  • Payment batch management and scheduling
  • Bank detail change tracking with approval workflow
  • Vendor management with bank detail verification
  • SLA tracking and analytics
  • Audit logging for full compliance traceability
  • Browser notifications for real-time alerts

System Architecture

ComponentTechnology
FrontendReact + TypeScript (Vite)
BackendNode.js + Express + TypeScript
DatabasePostgreSQL (Supabase)
OCR EngineOllama (qwen3:14b model)
External IntegrationNextGen (AVPS) for PO/MPO validation
DeploymentVPS (5.223.78.194) + Netlify

6. Upload Invoice

[Screenshot]
Upload Page — Drag & drop PDF upload

Available to: Purchasing Coordinator, Accounting Associate, IT Admin

How to Upload

  1. Navigate to Upload Invoice from the sidebar
  2. Drag and drop a PDF file, or click to browse
  3. The system automatically:
    • Extracts text using OCR (Ollama qwen3:14b)
    • Parses invoice fields (number, date, vendor, amount, line items)
    • Validates against NextGen MPO data
    • Creates the invoice record
  4. Review the extracted data in the preview
  5. Click Confirm to save or Edit to correct

Auto-Processing

Invoices placed in the incoming-invoices/ folder on the server are automatically picked up every 30 seconds by the File Watcher service, processed through OCR, and routed to the Purchasing Coordinator.

8. Exceptions Management

[Screenshot]
Exceptions — Invoices with validation issues

Exception Types

  • Amount mismatch — Invoice amount doesn't match PO
  • Quantity variance — Quantities exceed PO limits
  • Missing PO — No matching PO found in NextGen
  • Vendor mismatch — Invoice vendor doesn't match PO vendor
  • Duplicate invoice — Same invoice number already exists

Actions

  • Resolve — Fix the issue and re-validate
  • Override — Approve despite exception (requires reason)
  • Escalate — Send to a manager for review
  • Reject — Reject the invoice

17. User Management

[Screenshot]
User Management — User list with stats, search, add/edit/delete

Available to: IT Admin, SuperAdmin only

17.1 User List

  • Stats summary — Total, active, inactive, admin count
  • Search — By name, email, or role
  • Role color coding — Each role has a distinct color
  • Active/Inactive toggle — Power icon to activate/deactivate

17.2 Adding a User

  1. Click Add User (top-right, green button)
  2. Fill in the modal:
    • Name — Full name
    • Email — Must be unique
    • Role — Select from dropdown
    • Password — Minimum 4 characters (eye icon to toggle visibility)
    • Active — Toggle on/off
  3. Click Save

17.3 Editing a User

  1. Click the Edit (pencil) icon
  2. Modify name, email, role, password, or active status
  3. Click Save
  4. Changes take effect on next login

17.4 Deleting a User

  1. Click the Delete (trash) icon
  2. Confirmation modal appears with warning
  3. Click Delete Permanently to confirm
Restrictions: You cannot delete your own account or the last SuperAdmin account.

17.5 Activate/Deactivate

Click the Power icon to toggle. Deactivated users cannot log in.
